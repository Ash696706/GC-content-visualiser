# GC Content Visualizer 🧬📊

A beginner-friendly Python project that calculates the GC and AT content of a DNA sequence and visualizes the results using a bar graph.

## What this project does

* Calculates the length of a DNA sequence
* Calculates GC content
* Calculates AT content
* Displays the results
* Creates a bar graph comparing GC and AT content

## Technologies Used

* Python
* Matplotlib
* Google Colab

## Example Output

For the given DNA sequence:

`ATGCCATCCGATCGATTACGGGA`

* DNA length: 15
* GC content: 53.33%
* AT content: 46.67%

## Learning Goal

This project was created while learning Python and beginner-level bioinformatics, with a focus on biological data visualization.
